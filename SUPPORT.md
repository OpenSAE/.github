# Support

Start with the README, runnable examples, and documentation in the repository you are using.

For reproducible errors, model or SAE compatibility requests, and feature suggestions, open an issue in that repository. Include the command, relevant versions, and the smallest public reproduction you can share. Check existing issues first.

For scientific questions about a specific paper, use the corresponding research repository instead of SAEBase unless the problem is with shared infrastructure.

To propose a research collaboration or join OpenSAE, use the contact information in the [organization profile](profile/README.md).

Report security vulnerabilities privately according to [SECURITY.md](SECURITY.md), not through a public issue. Community conduct concerns can be sent to the contact described in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
